# 흑백 세계 같은 포스트 프로세스
## 개요
포스트 프로세스 머티리얼과 머티리얼 파라미터 컬렉션을 사용하여 흑백 세계 분위기를 표현했습니다.

시중의 다른 게임들에는 종종 보이지 않는 다리나 벽이 설치된 레벨이 존재하는데, 이를 표현하고자 했습니다.
